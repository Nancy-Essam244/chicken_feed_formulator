# 🐔 Chicken Feed Formulator

A web application that helps formulate optimal chicken feed mixtures based on nutritional requirements.

## Features
- Select from 23 different ingredients
- Choose broiler age stage (Starter/Grower/Finisher)
- Get optimal mixture with 100g batch size
- Nutrient analysis and quality assessment
- Mobile-friendly interface

## How to Use
1. Select exactly 3 ingredients
2. Choose age range
3. Click Calculate to get results
